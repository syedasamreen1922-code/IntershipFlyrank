# React Application — Assignment Submission

## 1. Project Overview

This project is a React-based web application built independently with the help of AI as a development assistant.

The application focuses on creating a clean, user-friendly settings form with a responsive layout that works across desktop, tablet, and mobile screen sizes.

The project was developed using React and Vite, with CSS used for styling and responsive behavior.

## 2. Technologies Used

* React
* Vite
* JavaScript
* HTML
* CSS
* Git and GitHub
* AI development assistants

## 3. AI Prompts Used During Development

### Prompt 1 — Initial UI

> Build a clean and modern settings form using React. Organize the settings into logical sections and make the interface easy for everyday users to understand.

### Prompt 2 — Component Structure

> Convert the settings form into a React application using reusable components. Keep the component structure simple and maintainable.

### Prompt 3 — Styling

> Improve the CSS styling of the React settings form. Focus on spacing, typography, form controls, buttons, visual hierarchy, and a clean modern appearance.

### Prompt 4 — Responsive Design

> Make the React settings form fully responsive for desktop, tablet, and mobile screens. Prevent horizontal scrolling and make sure inputs and buttons remain usable on smaller screens.

### Prompt 5 — Review and Improvements

> Review the current React application and identify layout, styling, usability, and responsive issues. Suggest improvements without unnecessarily changing the existing functionality.

## 4. How AI Assisted During Development

AI was used as a development assistant throughout the implementation process. It helped with planning the UI structure, creating React components, generating initial CSS, improving responsive behavior, and identifying possible issues in the application.

AI suggestions were reviewed rather than being accepted blindly. The generated code was tested in the browser and adjusted when necessary. AI was also used to help identify better ways to organize the application and improve the user experience.

Git was used throughout the development process to track changes. Separate branches were used during development, including a vague-prompt version and a more precise-prompt version. The final React implementation was merged into the main branch and pushed to GitHub.

## 5. Manual Improvements and Corrections

After reviewing the AI-generated implementation, manual improvements were made to the project.

Examples include:

* Adjusting spacing and sizing to improve the visual layout.
* Reviewing the form at different screen sizes.
* Checking the application on mobile, tablet, and desktop layouts.
* Correcting responsive behavior where necessary.
* Reviewing CSS for unnecessary or repetitive styling.
* Testing the form manually in the browser.
* Reviewing the final UI instead of relying only on AI-generated output.
* Refactoring and organizing the project files as the implementation progressed.

These changes helped make the final application more consistent, usable, and suitable for submission.

## 6. Responsive Testing

The application was tested at different viewport sizes to verify responsive behavior.

The following were checked:

* Desktop layout
* Tablet layout
* Mobile layout
* Input field sizing
* Button visibility and usability
* Text wrapping
* Spacing and alignment
* Horizontal overflow

The application remained usable across the tested screen sizes.

# Settings Form with Validation

## The Problem

I needed to build a settings form where users could update their profile and preferences without submitting invalid information. The form needed to handle both basic profile details and preference settings clearly.

## What I Did

I built the form with fields for display name, email, username, bio, email notifications, theme, and language.

I added validation rules based on the requirements. Display name was required, email had to use a valid format, usernames could contain only letters, numbers, and underscores, and bios were limited to 500 characters. Theme and language selections were also required.

I built the feature twice as part of my AI workflow practice. The first version used a vague prompt. For the second version, I gave AI more specific requirements, file references, constraints, and a verification step.

I also wrote validation and API tests to check that valid submissions were accepted and invalid submissions were rejected with the expected errors.

## What Came of It

The completed form correctly handled valid and invalid input, and the validation and API tests passed. The workflow also showed me that giving AI clear requirements and verification steps gave me more control over the result and made the work easier to review.
